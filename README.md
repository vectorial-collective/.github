# Vectorial Collective

Welcome to the central GitHub organization for Vectorial Collective, a student-led initiative dedicated to building free, open-source computational tools and helping others earn recognition and expand and improve their skills. We believe the best way to learn physics and engineering is by building things that actually run.

## Examples of Projects
- **Computational Physics:** Simulating physical systems, orbital mechanics, atmospheric drag, and classical dynamics using Python.
- **Open-Source Hardware & CAD:** Exploring mechanical design principles
- **Harvard CS50P:** Work through the official Harvard CS50P coursework with help from a community

## 🌐 Get Involved
Vectorial Collective is entirely open-source. Whether you're a student looking to collaborate, test code, or contribute to simulation libraries:
1. Explore our public repositories.
2. Fork a project and open a pull request.
3. Join our community build sessions!

*Founded with a mission to make advanced engineering simulation accessible and teachable to every student.*
